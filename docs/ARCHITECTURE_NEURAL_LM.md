# HOSKEY Neural LM Architecture

## Обновленное понимание

### Компоненты Yandex Keyboard

```
┌─────────────────────────────────────────────────────────────┐
│                    USER INPUT                               │
│                      "прив"                                 │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  TRIE (4.3 MB) - Prefix Filter / Subword Vocabulary         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Main Level: first tokens (characters/subwords)     │   │
│  │  Sub Level:  continuation tokens                    │   │
│  └─────────────────────────────────────────────────────┘   │
│  Function: Find valid prefixes → Token IDs                  │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  NEURAL LANGUAGE MODEL (42 MB)                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Input: Token IDs from trie                         │   │
│  │  Output: Probabilities for next tokens              │   │
│  │  Function: Generate/rank word completions           │   │
│  └─────────────────────────────────────────────────────┘   │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  RANKER (1.4 MB) - Final scoring                            │
│  Function: Context-aware ranking of candidates              │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  SUGGESTIONS                                                │
│  ["привет", "привез", "привезти", ...]                      │
└─────────────────────────────────────────────────────────────┘
```

## Trie не содержит слов!

### Что реально в trie
- **402,824 узлов** = subword токены
- **362,860 labels** = token IDs
- **Структура**: prefix tree для быстрого matching

### Пример
```
Trie содержит:
  "п" → "ри" → "вет"  (токены)
  
НЕ содержит:
  "привет" (целое слово)
  
Neural LM комбинирует:
  ["п", "ри", "вет"] → "привет" (слово)
```

## HOSKEY Adaptation

### Phase 1: Fallback (Current)
- Используем `extracted_words.txt` (108K слов)
- Simple prefix matching по словам
- Без neural generation

### Phase 2: Hybrid
- Trie для prefix validation
- Neural ranker (MindSpore Lite)
- Fallback на word list для редких слов

### Phase 3: Full Neural
- Trie только для tokenization
- Полная генерация через Neural LM
- Как в современных LLM

## Преимущества подхода

1. **Меньше памяти**: 4.3MB trie + 42MB model vs 500MB+ word list
2. **Генерация**: Можно создать слова не в словаре
3. **Морфология**: Автоматическая обработка окончаний
4. **Адаптивность**: Модель учится на пользователе
